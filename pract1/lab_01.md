# Задачи

### 1. Частота слов в файле
Напишите функцию, принимающую имя текстового файла и подсчитывающую частоту слов.

Формат вывода:
```text
<слово>: <количество>
```

**Что нужно знать:**
- `dict`;
- чтение файлов;
- разбиение строки на слова.

### 2. Key-value хранилище
Напишите CLI-утилиту `storage.py`, которая хранит данные в файле `storage.data`.

Добавление значения:
```bash
storage.py --key key_name --val value
```

Получение значений:
```bash
storage.py --key key_name
```

Требования:
- `--key` — имя ключа;
- `--val` — добавляемое значение;
- значения по одному ключу не перезаписываются, а добавляются;
- при чтении выводятся в порядке добавления;
- несколько значений выводятся как:
  ```text
  value_1, value_2
  ```
- если значений нет — вывести пустую строку или `None`.

**Подсказки:** `argparse`, `json`, `tempfile`.

### 3. Класс вектора на плоскости
Реализуйте класс вектора и перегрузите операции:
- сложение и вычитание;
- `==` и `!=`;
- умножение вектора на число;
- скалярное произведение;
- получение длины;
- `print()` в формате `<x; y>`;
- отображение объекта в интерпретаторе в формате `<x; y>`.

### 4. Иерархия плоских фигур
Реализуйте классы для вычисления площади:
- прямоугольника;
- треугольника;
- круга.

Базовый класс должен иметь чисто виртуальный метод `square()`. Производные классы должны переопределять его и хранить название фигуры (`Circle`, `Rectangle`, ...).

### 5. Singleton-логгер
Реализуйте класс для логирования сообщений в файл.

Формат:
```text
[<статус>] <время вывода>: <сообщение>
```

Статусы:
- `DEBUG`
- `INFO`
- `WANR`
- `ERROR`
- `CRITICAL`

В проекте должен существовать только один экземпляр логгера.


### 6. Числа Фибоначчи: три способа и декоратор замера времени

Напишите модуль `fib.py`, который формирует список чисел Фибоначчи тремя способами и измеряет время работы каждого способа с помощью декоратора.

**Требования**

- Функция `next_fib(a, b)` принимает два последовательных числа Фибоначчи и возвращает следующее число: `a + b`.
- Функция `fib_while(a, b, n)` возвращает список из `n` чисел Фибоначчи, начиная с `a` и `b`, используя цикл `while`.
- Функция `fib_range(a, b, n)` делает то же самое, но использует цикл `for` и `range`.
- Функция `fib_generator(a, b, n)` использует генератор (`yield`), а затем возвращает список через `list(...)`.
- Во всех трёх функциях следующее число должно вычисляться **только** через `next_fib(a, b)`.
- Декоратор `@timeit`:
  - измеряет время выполнения функции через `time.perf_counter()`;
  - выводит имя функции и затраченное время;
  - возвращает результат исходной функции;
  - использует `functools.wraps`;
  - должен быть универсальным и применяться ко всем трём функциям.


### 7. Декоратор с историей вызовов

Напишите модуль `timing.py`, в котором реализован декоратор `TimeIt`, сохраняющий историю всех вызовов декорируемой функции.

**Требования**

- Декоратор реализуется **как класс**, а не как обычная функция.
- Класс `TimeIt` принимает функцию и при вызове декорируемой функции:
  - замеряет время выполнения через `time.perf_counter()`;
  - сохраняет в историю запись о вызове;
  - возвращает результат исходной функции.
- Каждая запись истории должна содержать:
  - имя функции;
  - аргументы, с которыми функция была вызвана (`args`, `kwargs`);
  - результат выполнения (либо тип исключения, если оно возникло);
  - затраченное время;
  - момент вызова (например, `datetime.now()`).
- История должна быть доступна снаружи, например через атрибут `history`.
- У класса должны быть методы:
  - `last()` — вернуть последнюю запись истории;
  - `count()` — вернуть количество вызовов;
  - `clear()` — очистить историю;
  - `report()` — вывести историю в читаемом виде.
