## Что требуется сделать

В рамках практической работы необходимо разработать REST API учебной информационной системы на Python 3.13 с использованием FastAPI, Pydantic v2, SQLAlchemy 2.x, Alembic и PostgreSQL/SQLite. Нужно реализовать токен-аутентификацию, хранение токенов в отдельной таблице, настройку времени жизни токена через `.env`, разграничение доступа по ролям `teacher` и `student`, а также модули `Session`, `Disciplines`, `Student` и отдельный модуль обработки ошибок. Приложение должно поддерживать автоматические миграции при старте, начальные учётные записи, операции с дисциплинами, оценками, расписанием и средней успеваемостью, а также единый формат ошибок для 4xx/5xx. Доступ к данным студента должен проверяться через `Depends`(прослойка до выполнения логики метода `api`): студент работает только с `self`, преподаватель — с любым существующим `student_id`. В результате должно получиться запускаемое FastAPI-приложение с документацией Swagger/OpenAPI.

## Функциональные требования

### 1. База данных и миграции

- Создать миграции для всех таблиц.
- Начальные данные: 4 учётные записи (2 преподавателя, 2 студента).
- Миграции запускаются автоматически при старте приложения и корректно обрабатывают ситуацию, когда таблицы уже существуют.

### 2. Модуль `Session`

- Ручка логина по заранее созданным учёткам.
- Выдача токена; токены хранятся в отдельной таблице.
- Время жизни токена задаётся через `.env`.
- Ручка принудительного продления срока действия токена.
- Проверка токена и ролей (`teacher` / `student`) реализуется через `Depends`.

### 3. Модуль `Disciplines`

Единый набор ручек для обеих ролей. Разграничение доступа выполняется **на уровне проверки токена через `Depends`**, а не за счёт отдельных эндпоинтов:

- **Студент** обращается только к своему `self`. Запрос к чужому `student_id` возвращает `403`.
- **Преподаватель** может обращаться к любому `student_id`:
  - `GET`-ручки — просмотр данных любого студента;
  - `POST` / `PUT`-ручки — редактирование данных любого студента (создание и изменение дисциплин, оценок, расписания).

### 4. Модуль `Student`

Содержит ручки, связанные со студентом и не относящиеся напрямую к дисциплинам:

- Просмотр средней оценки по всем дисциплинам.
- Получение списка всех студентов (только `teacher`).

### 5. Модуль обработки ошибок

- Отдельный модуль `errors` (или `exceptions`).
- Содержит **схемы ошибок** (унифицированные ответы для 4xx/5xx).
- Содержит описание всех возможных ошибок и исключений приложения.

### Требования к схемам

- Каждый функциональный модуль (`Session`, `Disciplines`, `Student`) определяет **собственные Pydantic-схемы** для успешных ответов (HTTP 200).
- Схемы ошибок вынесены **в отдельный модуль обработки ошибок** и переиспользуются всеми модулями через общий обработчик исключений.

## Перечень эндпоинтов

### Модуль `Session`

| Метод | URL | Роль | Описание |
|-------|-----|------|----------|
| `POST` | `/session/login` | any | Логин по заранее созданной учётке, выдача токена |
| `PUT`  | `/session/refresh` | any (по токену) | Принудительное продление срока действия токена |

### Модуль `Disciplines`

Доступ: `student` (только `self`), `teacher` (любой `student_id`, включая запись).

| Метод | URL | Роль | Описание |
|-------|-----|------|----------|
| `GET`  | `/disciplines/{student_id}` | student / teacher | Список дисциплин студента (`self` или любой) |
| `POST` | `/disciplines/{student_id}` | teacher | Создать дисциплину у студента |
| `PUT`  | `/disciplines/{student_id}/{discipline_id}` | teacher | Изменить дисциплину студента |
| `GET`  | `/disciplines/{student_id}/grades` | student / teacher | Все оценки по предметам |
| `POST` | `/disciplines/{student_id}/grades` | teacher | Добавить оценку студенту |
| `PUT`  | `/disciplines/{student_id}/grades/{grade_id}` | teacher | Изменить оценку студента |
| `GET`  | `/disciplines/{student_id}/schedule` | student / teacher | Расписание дисциплин |
| `POST` | `/disciplines/{student_id}/schedule` | teacher | Добавить занятие в расписание |
| `PUT`  | `/disciplines/{student_id}/schedule/{schedule_id}` | teacher | Изменить занятие в расписании |

> В URL вместо `{student_id}` студент обязан передавать `self`. Если студент передаёт чужой `id` — ответ `403 Forbidden`. Преподаватель может передавать как `self`, так и любой существующий `student_id`.

### Модуль `Student`

| Метод | URL | Роль | Описание |
|-------|-----|------|----------|
| `GET` | `/student/{student_id}/average` | student / teacher | Средняя оценка по всем дисциплинам студента |
| `GET` | `/student/all` | teacher | Получить список всех студентов |

> В URL `/student/{student_id}/average` студент обязан передавать `self` вместо `{student_id}`. Если студент передаёт чужой `id` — ответ `403 Forbidden`. Преподаватель может передавать как `self`, так и любой существующий `student_id`.

> Итого: `Session` — 2 ручки, `Disciplines` — 9 ручек, `Student` — 2 ручки.
